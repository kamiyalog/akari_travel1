# 日本音声データ管理協会 — HTML静的版

ブラウザだけで起動できる、GitHub Pages対応版です。Node.jsやビルド作業は不要です。

## ローカルで起動する

1. ZIPを展開します。
2. ルート直下の `index.html` をダブルクリックします。
3. Chrome、Edge、Firefoxなどのブラウザで本編アクセス確認画面が起動します。
4. 確認用パスワード `1001` を入力すると、ゲーム内のログイン画面が表示されます。
5. ゲーム内に表示済みのID・PASSは入力不要です。「ログイン」を押すと管理ページへ進みます。

`index.html` だけを別の場所へ移動せず、`styles.css`、`data.js`、`game.js`、`audio`、`assets`と同じ構成のまま使用してください。

## GitHub Pagesで公開する

1. このフォルダの中身を、GitHubリポジトリのルートへアップロードします。
2. GitHubのリポジトリで `Settings` → `Pages` を開きます。
3. `Source` を `Deploy from a branch` にします。
4. 公開ブランチを `main`、フォルダを `/(root)` にして保存します。
5. 公開処理の完了後、表示されたURLから起動します。

GitHub Pagesは公開元の最上位にある `index.html` を入口として使用します。このZIPでは、最初からその構成にしてあります。

公式手順：
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## ファイル構成

- `index.html`：ゲーム起動ファイル
- `styles.css`：画面デザイン
- `data.js`：全音声データ、検索語、文字起こし
- `game.js`：検索、履歴、音声再生、分岐、エンディング
- `audio/`：完成したWAVファイルの配置先
- `assets/`：OGP画像とファビコン
- `voice-check/`：声優向け収録音声確認ページ
- `日本音声データ管理協会_ver.4.xlsx`：全キャラ台本とGOOD END（明坂音夢）収録台本
- `.nojekyll`：GitHub Pages用設定

すべて相対パスで接続しているため、GitHubのリポジトリ名が変わってもそのまま動作します。

## 音声ファイル

完成したWAVファイルを `audio/` に配置してください。必要なファイル名は `audio/README.md` に記載しています。

音声が未配置でも検索・文字起こし・エンディングまでは確認できます。通常の音声ページでは、再生ボタンを押した場合のみ音声ファイルの確認メッセージが表示されます。

各音声ページの文字起こしは初期状態では非表示です。「文字起こしを表示」ボタンで開閉できます。No.23以降は、本文の読みやすさを保ったまま、枠線や再生部分の警告色が終盤に向けて段階的に強まります。

GOOD ENDは34ページのビジュアルノベル形式です。通常の管理画面から切り替わり、場面を画面全面に表示し、下部の名前欄付きテキストボックスへ文章を表示します。画面内のボタン以外をクリック（キーボードではEnter／Space）すると次の文章へ進みます。ノベル中には進行度や操作メニューを表示しません。

各ページにつき1本、`NEMU-GOOD-001.wav`から`NEMU-GOOD-034.wav`までを使用します。ページが表示されると、そのページの音声を行単位で分割せず1本で自動再生します。34ページ目の次に、白い最終報告画面「通報を受け付けました。」を表示します。

## ページ移動と個別URL

TOP、音声データ管理、各音声、各エンドには、それぞれ固有のURLがあります。ブラウザの「戻る」「進む」で主要画面を移動でき、音声一覧や履歴の項目は右クリックの「新しいタブで開く」、Ctrl＋クリック、Command＋クリックにも対応しています。

例：No.23は公開URLの末尾が`#record/23`、GOOD ENDは`#end/good`になります。GOOD ENDのノベル内部は個別URLやブラウザ履歴を作らず、一つの画面内で順番に進行します。URLは相対指定のため、ローカル起動とGitHub Pagesのどちらでも同じように動作します。

## クレジット

音声データ管理ページと各エンドページの「クレジット」ボタンから表示できます。

音声データ管理ページでは物語上の重大なネタバレを避けるため、森高宵を「■■ ■」、明坂朱里を「■■ ■■」、明坂音夢を「■■■■」と表示します。GOOD END・BAD ENDでは役名が開示されます。制作名義は「久瀬」です。

キャスト情報は`data.js`先頭の`credits`にまとめています。明坂音夢役が決定したら、`audioPrefix: "NEMU"`の行にある`voiceActor: "未定"`を声優名へ変更してください。ゲーム内クレジットと声優確認ページの両方へ反映されます。

## 声優向け収録音声確認ページ

- ローカル起動：`voice-check/index.html`を開く
- GitHub Pages：公開URLの末尾へ`/voice-check/`を付けて開く
- 確認用パスワード：`0901`

パスワード解除後、役名で表示を絞り込み、その役の音声を一覧から直接再生できます。明坂音夢を選ぶと、GOOD ENDの34ファイルだけを続けて確認できます。別の音声を再生すると、先に再生していた音声は自動停止します。各音声の台本も同じ画面で確認できます。

役名を選ぶとURLにも担当役が反映されます。そのURLを声優さんへ渡せば、パスワード解除後すぐに該当役だけを表示できます。

このパスワードは静的HTML上の簡易的な表示制限です。GitHub Pagesへ公開したファイルそのものを秘匿する機能ではありません。

## ゲーム本編の確認用パスワード

- 本編確認用パスワード：`1001`
- 解除状態は同じブラウザタブ内だけで保持されます。ページ更新や本編内の「戻る」「進む」では再入力不要です。
- 新しいタブで本編URLを開いた場合は、再度パスワード入力が必要です。

ユーザー公開時は、`game.js`先頭付近の`GAME_ACCESS_REQUIRED`を`false`へ変更すると、本編アクセス確認画面を無効化できます。

本編側のパスワードも静的HTML上の簡易的な表示制限です。ソースファイルや音声データ自体を暗号化・秘匿するものではありません。

## セーブデータ

検索済みデータ、閲覧履歴、現在ページはブラウザの `localStorage` に保存します。

ローカル版とGitHub Pages版は保存先が別になるため、進行状況は共有されません。
